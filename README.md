# Project Plutus – Stock Market Analysis

This project was developed as part of the HackMIT-WPU’24 Ideathon.

## Overview
A research-based project focused on analyzing stock market trends and investor behavior, especially before and after the COVID-19 pandemic.

## Key Highlights
- Analysis of youth participation in stock markets
- Study of factors like digital platforms, social media, and volatility
- Understanding financial concepts such as candlestick patterns
- Insights into post-COVID trading behavior

## Future Scope
Planned extension into a system that can assist in analyzing market trends.

This repository contains research and conceptual work from a hackathon project.
